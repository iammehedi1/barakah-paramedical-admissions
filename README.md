# BCPI Website

**Live Site:** https://iammehedi1.github.io/bcpi-website

Official website of **Barakah Community Paramedical Institute (BCPI)** - a Nursing Council approved institution in Dhaka, Bangladesh.

### About

BCPI offers a 2-year **Community Paramedic (CP) course** approved by Bangladesh Nursing & Midwifery Council. The course includes 4 semesters (6 months each) with internship opportunities at government hospitals and community clinics.

### Features

- Fully responsive design (mobile, tablet, desktop)
- Bengali language interface
- Mobile-optimized with sticky call buttons
- WhatsApp & phone integration
- Google Maps integration
- Modern UI with green gradient accents

### Courses

- **CP (Community Paramedic)** - 2 years, 4 semesters

### Tech Stack

- Pure HTML5, CSS3, JavaScript
- Google Fonts (Noto Sans Bengali)
- No build tools required

Open `index.html` in any browser.
